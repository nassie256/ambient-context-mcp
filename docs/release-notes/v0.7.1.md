## Ambient Context MCP v0.7.1

v0.7.0 (WPF → WinUI 3 移行) のリリース成果物に「設定ダイアログが開かない」パッケージング不具合があったため、それを修正した再リリースです。**v0.7.0 ではなく本 v0.7.1 をご利用ください。** アプリのコード自体は v0.7.0 と同一で、変更はリリースビルドの方法のみです。

### Bug fixes

- **設定ダイアログが開かない不具合を修正**: v0.7.0 の配布物は `dotnet publish` で生成していましたが、これは Unpackaged WinUI 3 のコンパイル済み XAML (`.xbf`) とリソースインデックス (`.pri`) を出力に含めません。そのためトレイアイコンとメニューは表示されるものの、設定ダイアログを開こうとすると `XamlParseException` で失敗していました。リリースビルドを `dotnet build` ベースへ切り替え、XAML リソースを同梱するよう修正しています (アプリ本体のコード変更はありません)。

### v0.7.0 の主な変更 (再掲)

- **WPF → WinUI 3 (Windows App SDK 1.8) への移行**。設定 UI を Fluent / Mica 化。詳細は [v0.7.0 リリースノート](v0.7.0.md) を参照してください。
- **NVIDIA Optimus 機の「画面モードを切り替えできません」警告の解消** (本リリース群の主目的、D3D9Ex → D3D11)。
- MCP API・送信ポリシー・トレイ機能は v0.6.x と互換です。

### Requirements

- Windows 10 version 2004 (10.0.19041, May 2020 Update) 以降
- [.NET 8 ランタイム + ASP.NET Core 8 ランタイム (x64)](https://dotnet.microsoft.com/download/dotnet/8.0)
- [Windows App Runtime 1.8 x64](https://aka.ms/windowsappsdk/1.8/latest/windowsappruntimeinstall-x64.exe) (初回起動時に未導入なら案内されます)

### Install

**Claude Desktop の場合 (推奨)**

1. `ambient-context-mcp-v0.7.1.mcpb` をダウンロード
2. Claude Desktop の設定 → 拡張機能 からインストール
3. タスクトレイの `[●] Ambient Context MCP — :37690` を確認、設定ダイアログで送信ポリシーを調整

**Claude Code / その他クライアントの場合**

1. `ambient-context-mcp-v0.7.1-win-x64.zip` を任意のフォルダに展開
2. `ambient-mcp.exe` を起動 (未署名のため SmartScreen で「詳細情報」→「実行」)
3. タスクトレイ → 「Claude Code 用設定をコピー」 → ターミナルに貼り付け

```bash
claude mcp add ambient-context \
  --transport http http://127.0.0.1:37690/mcp \
  --header "Authorization: Bearer <TOKEN>"
```
