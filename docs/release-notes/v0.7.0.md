## Ambient Context MCP v0.7.0

Windows 常駐アプリを **WPF から WinUI 3 (Windows App SDK 1.8) へ移行**したメジャー更新です。NVIDIA Optimus 搭載機で発生していた「画面モードを切り替えできません」警告を解消し、設定 UI を Fluent / Mica スタイルへ刷新しました。MCP API・送信ポリシー・トレイ機能は v0.6.x と互換です。

### What's new

- **WPF → WinUI 3 への移行**: Windows 常駐クライアントを WinUI 3 (`Microsoft.WindowsAppSDK` 1.8) ベースに再実装しました。設定ダイアログは Fluent / Mica の外観になり、MCP Server / Transmission の 2 タブ構成・機能は従来どおりです。
- **NVIDIA Optimus 警告の解消 (本リリースの主目的)**: WPF は D3D9Ex デバイスをプロセス存続中ずっと保持するため、NVIDIA の Optimus が `ambient-mcp.exe` を「MUX 切替を妨げるアプリ」として検出し、フルスクリーンゲーム起動時に「画面モードを切り替えできません」警告を出すことがありました。WinUI 3 (DirectComposition + D3D11) はこの対象外のため、警告が出なくなります。

### Behavioral changes

1. **初回起動時に Windows App Runtime 1.8 のインストールが必要です**: 未導入の環境では起動時に案内が表示され、ダウンロードページ ([windowsappruntimeinstall-x64.exe](https://aka.ms/windowsappsdk/1.8/latest/windowsappruntimeinstall-x64.exe), 約 100 MB / UAC 必須 / 初回のみ) へ誘導されます。
2. **Windows 10 では設定ウィンドウの Mica が無効になり単色背景で表示されます** (機能差はありません)。
3. **設定 / トレイメニュー / MCP API はすべて v0.6.x と互換です**: 送信ポリシー設定ファイル、トレイの各メニュー、`/mcp` の 4 ツールおよび Bearer 認証はそのまま利用できます。
4. **アップグレード手順**: 旧 v0.6.x の `ambient-mcp.exe` を終了 → 新 v0.7.0 の zip を展開して上書き → 起動してください。

### Bug fixes

- **キーボードからトレイを操作できない不具合を修正**: トレイアイコンにキーボードでフォーカスしても、`Enter` やメニューキー (`Shift+F10`) で設定・右クリックメニューを開けない問題を修正しました (`Win+B` で通知領域へ → 矢印キーでアイコン選択 → `Enter` で設定)。

### Requirements

- Windows 10 version 2004 (10.0.19041, May 2020 Update) 以降
- [.NET 8 ランタイム + ASP.NET Core 8 ランタイム (x64)](https://dotnet.microsoft.com/download/dotnet/8.0)
- [Windows App Runtime 1.8 x64](https://aka.ms/windowsappsdk/1.8/latest/windowsappruntimeinstall-x64.exe) (初回起動時に未導入なら案内されます)

### Install

**Claude Desktop の場合 (推奨)**

1. `ambient-context-mcp-v0.7.0.mcpb` をダウンロード
2. Claude Desktop の設定 → 拡張機能 からインストール
3. タスクトレイの `[●] Ambient Context MCP — :37690` を確認、設定ダイアログで送信ポリシーを調整

**Claude Code / その他クライアントの場合**

1. `ambient-context-mcp-v0.7.0-win-x64.zip` を任意のフォルダに展開
2. `ambient-mcp.exe` を起動 (未署名のため SmartScreen で「詳細情報」→「実行」)
3. タスクトレイ → 「Claude Code 用設定をコピー」 → ターミナルに貼り付け

```bash
claude mcp add ambient-context \
  --transport http http://127.0.0.1:37690/mcp \
  --header "Authorization: Bearer <TOKEN>"
```
