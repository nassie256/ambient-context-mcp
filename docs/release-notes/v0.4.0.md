## Ambient Context MCP v0.4.0

Claude Desktop に向けた MCPB (`.mcpb`) バンドル配布を追加し、ツール ID をクライアント互換の形式に揃えた更新。

### What's new

- **MCPB バンドル配布開始**: `ambient-context-mcp-v0.4.0.mcpb` を Claude Desktop の設定 → 拡張機能 からインストールできるようになりました。バンドルは tray + 軽量 stdio ブリッジ (`ambient-mcp-stdio.exe`) を同梱し、tray 未起動なら自動 spawn、起動済みなら discovery file (`%LOCALAPPDATA%\AmbientContextMcp\mcp-api.json`) 経由で既存 tray に接続します。LocalContextHub の単一性は維持されます。

### Breaking changes

- **ツール ID をアンダースコア区切りに変更**:

  | 旧 (v0.3.0 以前) | 新 (v0.4.0 以降) |
  |---|---|
  | `ambient.context.get_states` | `ambient_context_get_states` |
  | `ambient.context.poll_events` | `ambient_context_poll_events` |
  | `ambient.context.get_policy` | `ambient_context_get_policy` |

  Claude Desktop / Anthropic Messages API / OpenAI Function Calling のいずれも `tools[].name` に `^[a-zA-Z0-9_-]{1,64}$` を強制しており、ドットを含む旧名はクライアント側 validation で reject されていました。MCP プロトコル仕様自体には文字制約はありませんが、現実の LLM クライアントとの互換性のためアンダースコア区切りに揃えました。
  既存クライアント設定からツール名を呼び出している場合は、新しい名前への置き換えが必要です。

### Requirements

- Windows 10 1903 (10.0.18362) 以降
- [.NET 8 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/8.0)

### Install

**Claude Desktop の場合 (推奨)**

1. `ambient-context-mcp-v0.4.0.mcpb` をダウンロード
2. Claude Desktop の設定 → 拡張機能 からインストール
3. タスクトレイの `[●] Ambient Context MCP — :37690` を確認、設定ダイアログで送信ポリシーを調整

**Claude Code / その他クライアントの場合**

1. `ambient-context-mcp-v0.4.0-win-x64.zip` を任意のフォルダに展開
2. `ambient-mcp.exe` を起動 (未署名のため SmartScreen で「詳細情報」→「実行」)
3. タスクトレイ → 「Claude Code 用設定をコピー」 → ターミナルに貼り付け

```bash
claude mcp add ambient-context \
  --transport http http://127.0.0.1:37690/mcp \
  --header "Authorization: Bearer <TOKEN>"
```
